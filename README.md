# 本科毕业论文工作区

启动日期：2026-11-03。当前方案：v1.3（排期优化版，2026-11-04修订）。计划毕业：2027年6月。

**暂定题目：《面向高曲率窄道路的自适应采样局部轨迹规划方法研究》**

主线：基线复现 → 失效分析 → 几何自适应采样 → 轻量学习引导采样 → 抗扰动与跟踪验证。

## 从这里开始

1. 先读 [论文方向与实验设计修订说明](docs/论文方向与实验设计_修订版.md)，再按 [完整执行方案](docs/毕业论文完整执行方案.md) 的范围和验收要求执行。
2. 按 [第一周任务单](docs/第一周任务单_2026-11-03至11-09.md) 优先完成一个官方基线示例的复现与证据归档，围绕运行流程阅读文献并补充实验设计。
3. 在 [任务与里程碑](docs/任务与里程碑.csv) 更新进度，在 [实验记录规范](docs/实验记录规范.md) 规定的字段中记录实验。
4. 文献按 [参考资料与阅读顺序](docs/参考资料与阅读顺序.md) 阅读，边实现边记录；可导入 [BibTeX文献库](references/references.bib)。

## 保留内容

- 论文方向、研究问题、技术路线和范围。
- 场景设计、方法对照、评价指标和实验记录要求。
- 参考文献、阅读顺序及BibTeX文献库。
- 写作安排、任务里程碑、实验记录与周报模板。

实验平台为Windows＋Ubuntu 22.04双系统；CommonRoad Reactive Planner规划实验、训练与跟踪仿真统一在Ubuntu 22.04下进行。此目录聚焦研究与写作资料。
