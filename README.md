1. **先读 [时间安排 v2](docs/时间安排_v2_2026-11-16起.md)**——阶段、门禁和降级规则只认它。再读 [本周任务](docs/本周任务_2026-11-16至11-22.md)（这周逐日做什么）和 [一页方向说明](docs/一页方向说明_2026-11-16.md)（范围与判定标准）。方法与实验定义见 [论文方向与实验设计修订说明](docs/论文方向与实验设计_修订版.md)。
2. 立刻要做的只有一件事：在 Ubuntu 上跑通官方示例并归档证据，见 [scripts/ubuntu_setup.sh](scripts/ubuntu_setup.sh) 与 [证据目录](experiments/2026-11-16_baseline/README.md)。
3. 在 [任务与里程碑](docs/任务与里程碑.csv) 更新进度，在 [实验记录规范](docs/实验记录规范.md) 规定的字段中记录实验。
4. 文献按 [参考资料与阅读顺序](docs/参考资料与阅读顺序.md) 阅读，边实现边记录；可导入 [BibTeX文献库](references/references.bib)。

- 论文方向、研究问题、技术路线和范围。

- 写作安排、任务里程碑、实验记录与周报模板。

实验平台为Windows＋Ubuntu 22.04双系统；CommonRoad Reactive Planner规划实验、训练与跟踪仿真统一在Ubuntu 22.04下进行。此目录聚焦研究与写作资料。
