# 基线复现证据（2026-11-16）

用途：完成里程碑 T03（可复现官方示例）。本目录只放**实际跑出来的东西**，没跑通的项留空并写明阻塞。

## 需要回答的四个问题

1. **跑通了吗？** 最后一行"current time step"是多少？最后是否到达目标区域？
2. **怎么终止的？** `goal_reached()` 返回真、无解退出、还是报错？
3. **能复现吗？** 两次重跑的最后时间步、终止原因是否一致？
4. **哪些地方还看不懂？** 列出 3–5 个待查的源码位置（比如采样等级如何递增、碰撞检查在哪里调用）。
