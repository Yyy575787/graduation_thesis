# 参考文献与阅读路线

核对日期：2026-11-03；版本：v1.1。下列13项为可用于毕设的候选参考，按与本课题的作用排列；正式格式以学校模板为准。提供[可导入BibTeX](../references/references.bib)。

核对依据包括作者论文、会议/出版社页面、机构仓储和DOI登记元数据。当前核对过书目信息及摘要/部分正文，不表示已逐页精读全部论文。预印本不写成已正式发表；已接收但未核对卷页的条目不补造页码。

## A. 必须先读的主线文献

**[1] Werling M, Ziegler J, Kammel S, Thrun S. Optimal trajectory generation for dynamic street scenarios in a Frenét Frame. ICRA, 2010: 987–993.**

- [机构记录](https://publikationen.bibliothek.kit.edu/1000022393)；DOI：[10.1109/ROBOT.2010.5509799](https://doi.org/10.1109/ROBOT.2010.5509799)。
- 用途：Frenet轨迹采样的基础，理解纵横向轨迹、终端参数、约束与代价。写理论章节并对照CommonRoad源码。
- 阅读问题：`d_T,T,v_T`如何决定轨迹；纵横向多项式为何分别选用不同阶次；轨迹连续性与动态可执行性有什么区别。

**[2] Werling M, Kammel S, Ziegler J, Gröll L. Optimal trajectories for time-critical street scenarios using discretized terminal manifolds. The International Journal of Robotics Research, 2012, 31(3): 346–359.**

- [出版社页面](https://journals.sagepub.com/doi/10.1177/0278364911423042)；DOI：10.1177/0278364911423042。
- 用途：进一步理解终端状态集合、轨迹生成和成本设计，支持候选参数空间的定义。
- 书目提醒：在线首发为2011年，所引期刊卷期为2012年，不把两个日期混为一谈。

**[3] Althoff M, Koschi M, Manzinger S. CommonRoad: Composable benchmarks for motion planning on roads. IEEE Intelligent Vehicles Symposium, 2017: 719–726.**

- [TUM机构记录](https://portal.fis.tum.de/en/publications/commonroad-composable-benchmarks-for-motion-planning-on-roads/)；DOI：[10.1109/IVS.2017.7995802](https://doi.org/10.1109/IVS.2017.7995802)。
- 用途：说明场景、车辆、约束和目标的可复现组织。用在平台与实验设计章节。
- 边界：CommonRoad是场景/基准体系，Reactive Planner是具体规划器，二者引用不能互相替代。

**[4] Würsching G, Althoff M. Robust and Efficient Curvilinear Coordinate Transformation with Guaranteed Map Coverage for Motion Planning. IEEE Intelligent Vehicles Symposium, 2024: 2694–2701.**

- [TUM机构记录](https://portal.fis.tum.de/de/publications/robust-and-efficient-curvilinear-coordinate-transformation-with-g/)；DOI：[10.1109/IV55156.2024.10588590](https://doi.org/10.1109/IV55156.2024.10588590)。
- 用途：高曲率道路的参考线、唯一投影域与转换可靠性，直接服务失效分类。
- 阅读问题：什么失败来自坐标表示，什么失败才可能由增加采样覆盖解决；该文保证不能转写为本项目自动具备的保证。

**[5] Ichter B, Harrison J, Pavone M. Learning Sampling Distributions for Robot Motion Planning. ICRA, 2018: 7087–7094.**

- [作者论文](https://arxiv.org/abs/1709.05448)；DOI：[10.1109/ICRA.2018.8460730](https://doi.org/10.1109/ICRA.2018.8460730)。
- 用途：条件生成模型引导采样的直接方法基础，重点阅读条件变量、监督样本、混合采样及实验比较。
- 边界：其面向机器人状态空间采样，本文学习车辆终端参数；不能直接移植其中完备性等结论。arXiv初稿为2017年，会议为2018年。

**[8] Barbera J M, Artuñedo A, Villagra J. Waypoints Matter: A Systematic Study for Sampling-Based Trajectory Planning. 2026. arXiv:2606.06366；作者页面标注已接收IEEE ITSC 2026。**

- [作者论文与接收说明](https://arxiv.org/abs/2606.06366)。当前不填未核对的正式会议页码。
- 用途：支持固定轨迹元、固定候选预算与认真调参的实验设计；提醒几何自适应并非在所有设置下都优于均匀采样。
- 边界：其使用五次Bézier轨迹与路点布置，本文为Frenet多项式终端参数采样，具体结果不能直接照搬。

## B. 方法设计与相关工作

**[6] Sohn K, Lee H, Yan X. Learning Structured Output Representation using Deep Conditional Generative Models. Advances in Neural Information Processing Systems 28, 2015.**

- [会议官方论文页](https://papers.nips.cc/paper_files/paper/2015/hash/8d55a249e6baa5c06772297520da2051-Abstract.html)。
- 用途：CVAE的条件、潜变量、重构项和KL项。用在模型原理部分，不将图像结构输出实验当成车辆规划结论。

**[7] Trauth R, Moller K, Würsching G, Betz J. FRENETIX: A High-Performance and Modular Motion Planning Framework for Autonomous Driving. IEEE Access, 2024.**

- [作者论文](https://arxiv.org/abs/2402.01443)；[作者代码及正式引用](https://github.com/TUM-AVS/Frenetix-Motion-Planner)；DOI：[10.1109/ACCESS.2024.3436835](https://doi.org/10.1109/ACCESS.2024.3436835)。
- 用途：模块化采样轨迹规划、运行效率和评价组织。先作为工程与相关工作参考，不同时迁移到第二套大框架。
- 书目提醒：作者仓库的BibTeX仍有`pages=1-1`等早期占位，本清单不沿用占位卷页。

**[9] Idoko S, Sharma B, Singh A K. Learning Sampling Distribution and Safety Filter for Autonomous Driving with VQ-VAE and Differentiable Optimization. 2024. arXiv:2403.19461.**

- [作者预印本](https://arxiv.org/abs/2403.19461)。本次未核对到正式出版信息，按预印本记录。
- 用途：了解生成分布的多模态覆盖、采样与安全滤波的分工。
- 边界：其提出可微优化安全滤波，本文以共同约束筛选为主；文中对CVAE的局限是其研究设置下的判断，不概括为所有CVAE都无法表示多模态。

**[10] Moller K, Stroop R, Piccinini M, Langmann A, Betz J. Learning to Sample: Reinforcement Learning-Guided Sampling for Autonomous Vehicle Motion Planning. 2025；2026-03修订. arXiv:2509.24313.**

- [作者论文](https://arxiv.org/abs/2509.24313)；[作者代码](https://github.com/TUM-AVS/Learning-to-Sample)。页面标注提交IEEE审稿，本清单不推断录用情况。
- 用途：最需要在相关工作中比较的近邻方法，已经结合CommonRoad、学习引导终端参数与解析轨迹评估。
- 本文可能的差别：聚焦高曲率受限静态场景、轻量离线监督、几何对照和观测误差；差别是否足以成为文章贡献仍需实验证据。

**[13] Rabenstein G, Ullrich L, Graichen K. Sampling for Model Predictive Trajectory Planning in Autonomous Driving using Normalizing Flows. IEEE Intelligent Vehicles Symposium, 2024: 2091–2096.**

- [作者论文](https://arxiv.org/abs/2404.09657)；DOI：[10.1109/IV55156.2024.10588765](https://doi.org/10.1109/IV55156.2024.10588765)。
- 用途：学习采样分布的另一条技术路线，为模型选择和时间开销讨论提供参考；本阶段不要求实现Normalizing Flow。
- 边界：其输入轨迹/MPPI采样与本文终端参数候选并不相同。

## C. 背景与控制验证

**[11] Paden B, Čáp M, Yong S Z, Yershov D, Frazzoli E. A Survey of Motion Planning and Control Techniques for Self-Driving Urban Vehicles. IEEE Transactions on Intelligent Vehicles, 2016, 1(1): 33–55.**

- [作者论文](https://arxiv.org/abs/1604.07446)；DOI：[10.1109/TIV.2016.2578706](https://doi.org/10.1109/TIV.2016.2578706)。
- 用途：绪论中区分路线规划、局部轨迹规划与跟踪控制；用于分类与系统边界，不依靠较早综述断言最新研究空白。

**[12] Coulter R C. Implementation of the Pure Pursuit Path Tracking Algorithm. Pittsburgh: Carnegie Mellon University, 1992. Technical Report CMU-RI-TR-92-01.**

- [CMU官方报告页](https://publications.ri.cmu.edu/implementation-of-the-pure-pursuit-path-tracking-algorithm)。
- 用途：实现统一跟踪控制器、理解前视距离影响。它是技术报告，不标成期刊或会议论文。
