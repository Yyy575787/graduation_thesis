# 实验记录与论文结果整理规范

版本：v1.2，2026-11-03。用于支撑毕业论文的实验设计、结果分析和图表写作。当前记录模板为空，尚未形成实验结果。

## 1. 每次实验至少记录什么

记录实验日期、研究问题、方法组、场景编号、道路几何、障碍物条件、初始状态、候选预算、扰动设置、随机种子、实际结果与结论。参考[实验记录模板](../templates/实验记录模板.csv)。

同一道路几何及其全部障碍物、初始状态、扰动版本保持同一训练/验证/测试归属。记录场景与数据来源，防止数据泄漏。

## 2. 方法对照与控制条件

B0为合理调参的传统采样基线，B1为几何自适应采样，B2为学习混合采样。各组共用车辆模型、参考线处理、安全约束、代价函数、控制器、目标区域与终止规则。

等候选预算和等计算时间分别比较。候选预算按实际累计数量计算，包含分层采样与补采样；网络推理、预筛、检查、选择和回退均计入规划时间。

理想轨迹执行与自行车模型跟踪分别报告，不能混为同一种闭环结果。

## 3. 结果指标

| 指标 | 写作口径 |
|---|---|
| 任务完成率 | 成功到达目标的完整任务数/总任务数，包含失败与超时 |
| 无解与连续无解 | 区分单周期无解与整任务失败，同时记录最长持续周期及秒数 |
| 碰撞与越界 | 基于真实环境中的实际车身包络评价 |
| 最小净距 | 分别记录车身到障碍物和道路边界的距离 |
| 轨迹质量 | 曲率、曲率变化、加速度与jerk，注明单位和计算方式 |
| 耗时 | 平均、P95与超时率，包含失败周期 |
| 进展与保守性 | 到达时间、平均速度和停车时长 |
| 有效候选 | 只将完成全部共同约束检查的候选计为可行，注明分母 |

没有测量的指标留空并说明原因，不能用0代替未知。停车或紧急制动不自动等于任务完成。

## 4. 失败案例

分类记录坐标/参考线、轨迹生成、车辆约束、障碍物碰撞、道路越界、预算或时间耗尽等原因。无法从原方法区分的类别合并报告，不补造细分结果。

第一拒绝原因与全部违反约束的多标签统计分开。检查顺序会影响第一拒绝比例，因此各方法固定检查顺序。因早停而未检查的候选标为未检查，不能直接判断可行性。

高预算未找到解不能直接证明物理无解。失败案例保留实际场景图、轨迹图和必要数据，并说明适用边界。

## 5. 统计与论文图表

同一场景、同一扰动种子配对比较。以基础道路几何为分组统计，避免把同一道路上的大量周期当成独立道路样本。

成功率报告区间或分组差异；耗时报告分布。若轨迹质量仅统计成功任务，标明这一条件，并补充共同成功任务的配对结果。

每张图表对应明确的研究问题、场景集合、方法版本、预算和扰动条件，保留其原始数据。图注区分实测结果、设计示意与外部来源。文献结果不当成本项目结果。

参数调优只使用开发集合。正式测试后修复影响正确性的问题，应重跑受影响对照并说明变更，不能依据测试表现重新挑选场景。

## 6. 阶段报告

每个阶段报告包含：研究问题、实验条件、对照方法、实际结果、统计图表、失败解释、局限和下一步。没有取得预期收益也应保留证据与分析，避免将拟定目标写成已达成结果。
