# 一页方向说明（T02 交付物）

日期：2026-11-16。状态：草案，待导师确认。依据：[方向与实验设计](论文方向与实验设计_修订版.md)、[完整执行方案](毕业论文完整执行方案.md)、[贡献评估](科学贡献与投稿潜力评估_2026-11-03.md)。本文只做决定，不新增研究范围。

## 1. 一句话说清做什么

在**已知边界的急弯窄路**上，为一台**低速前进车辆**做 Frenet 局部轨迹规划；研究的问题不是"换个更好的网络"，而是：

> **候选数固定时（32/64/128/256），采样点应该按什么规则分配到 `(d_T, T, v_T)` 空间，才能让"找到可行且有进展的轨迹"的概率更高？**

判断手段只有一条：同一生成器、同一约束、同一预算下，**成功率—预算曲线**的形状。曲线上移或左移，方法才算有用。

## 2. 主线押 B1，不押 B2

| 部分 | 定位 | 理由 |
|---|---|---|
| B0 基线 | 必做 | 官方生成器 + 固定网格/规则采样 + 统一预算计数 |
| **B1 几何自适应** | **论文主线** | 便宜、可解释、可写成公式与伪代码；"曲率+净空 → 预算分配"是可被检验的机制 |
| B2 CVAE 混合采样 | 加分项，最后做 | 已被 Ichter 2018[5] 与 Moller 2025[10] 做过，最贵、最不原创；没有稳定收益时按"已完成探索"如实写 |
| E3 扰动 | 降级为"适用边界评估" | 方法里没有针对观测误差的机制，就不宣称鲁棒性 |
| E4 跟踪 | 必做但最小化 | 证明改进不是只在理想轨迹回放里成立 |

## 3. 三个假设与判定标准

| 假设 | 实验 | 算成立的条件 |
|---|---|---|
| H1：存在真实的采样瓶颈——高预算有解、低预算常无解，且不是坐标或建模错误 | E1：24 个开发任务 × 32~512 + 2048 参考 | 至少一类场景里，2048 能找到、≤128 系统性找不到；且失效原因不是投影/车身表达 |
| H2：用前方曲率与可用空间分配预算，同预算下更好 | E2：B0 vs B1，配对比较 | 64/128 档成功率差值按几何分组 bootstrap 的 95% 区间不跨 0，**或**达到同等成功率所需预算下降 ≥1 档 |
| H3：学习分布能在 B1 之上再赚一点 | E2：B1 vs B2 | 只在 H2 成立且时间有余时开机；不成立就写"未观察到额外收益及原因" |

H1 不成立时，论文改写成"参数敏感性 + 失效机制分析"，仍然是合格本科论文，**不要**用加大网络来掩盖。

## 4. 论文六章各一句

1. 绪论：局部轨迹规划在受限道路上的采样效率问题，为什么值得研究。
2. 理论与平台：Frenet 坐标、五次多项式、车辆约束、CommonRoad/Reactive Planner 流程。
3. 方法：失效依据 → B1 的分配公式与伪代码 →（可选）B2 条件与混合比例。
4. 实验设计：场景参数、划分、预算与计时口径、指标定义。
5. 结果：预算曲线、候选分布、失败分类、扰动边界、跟踪效果。
6. 总结：成立的范围、不成立的部分、可复用产物。

## 6. 变量与指标

- 自变量：道路半径（8/14/20 m）、路宽（车宽+0.8/+1.6 m）、转向（左/右）、障碍物（无/有）、候选预算（32/64/128/256/512，参考 2048）。
- 控制变量：同一车辆参数、同一参考线预处理、同一约束阈值、同一代价函数、同一速度策略（2 m/s）、初始偏差 0。
- 因变量：任务完成率、单周期无解率、有效候选率、P95 规划耗时、最小车身净距、到达耗时。
- 统计：按 `geometry_id` 分组 bootstrap 报 95% 区间；配对任务同种子。
