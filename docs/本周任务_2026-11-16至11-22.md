## 平台前提

Windows 装不了 `commonroad-drivability-checker`（PyPI 只有源码包，包内测试文件名含 Win32 非法字符 `:`），实测在 `pip install` 阶段失败。规划实验统一在已有的 Ubuntu 22.04 分区进行，仓库在 `/mnt/d`，虚拟环境在 Linux 家目录。

## 卡住时

- 同一个报错超过 2 小时：记录已尝试命令与报错，问人，不在 Windows 上重试。
- 缺 `python3-venv`：`sudo apt install -y python3-venv`。
- 找不到 `/mnt/d`：先在 Ubuntu 里确认 NTFS 挂载，再跑脚本。
