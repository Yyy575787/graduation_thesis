World4Scorer

“以决策为中心”的“世界模型”

非完整的未来图像或像素级演化
↳ 潜在状态承载的是候选轨迹的结果信息

一、核心前向架构与预测器内部结构

输入
4-view Images
经 DINOv2 编码
场景表征
Scenario Token st
4 视角相机编码输出的 15,744 个图像特征
候选生成
Trajectory Generator
输出 N = 64 候选轨迹
τt,i (i = 1, 2, …, 64)
动作编码 sg
Action Encoder φ
qt,i = φ(sg[τt,i])
Qt shape: (N, 256)
sg stop-gradient（停止梯度）

在 PyTorch 中对张量调用 .detach()；截断 Lscore 到 φ 输入端，使生成器只听 LWTA。

Query Token 汇总与输入

qt,i = φ(sg[τt,i])，汇总为矩阵 Qt = [qt,1, …, qt,N]（shape (N, 256)），连同 st 一同送入 P。

4 层

Latent World Model P

P 内部模块结构
① Self-Attention

Q, K, V 来自 τi, τj；用 τi 和所有 τj 做注意力，实现横向比较学习。

② Cross-Attention

Q 来自 τi，K, V 来自 st；τi 将自身特征放到 st 中做预测学习。

③ FFN（Feed-Forward Network）

两层 MLP：256 → 1024 → 256，对融合特征做非线性提炼。

经输出归一化得：Zt = P(Qt, st)，其中 Zt 第 i 行 zt,i 为候选轨迹 i 的预测状态
融合：场景环境 + 同池竞争关系

二、评分读取与对数域排序得分

P → Zt → Score Heads H ← et (自车状态)
ℓt,i = H(zt,i + et)
令 pt,i,m = σ(ℓt,i,m)
乘性组 G： {NC, DAC, DDC}
加性组 A： {TTC, EP, C}
排序得分
Ĵt,i = Σm∈G αm log pt,i,m + log( Σm∈A βm pt,i,m )
αm, βm 为各项权重

三、互补训练监督：结果标签监督 + 以轨迹为条件的 JEPA

Each train scene supplies: label → 80 条 · future target → exec one
生成候选轨迹（64 条） + 轨迹库候选轨迹（16 条）
→ 缺乏未来观测
↑ 监督：结果标签 yi
结果损失函数（式 5）
Lout = Lscore + λbank Lbank = Σi wi ℓout(H(zi + e), yi)

yi 要求模型在 G（安全硬约束）和 A（进度/舒适度）上做出区分。

实际运行轨迹（1 条 · τtexec）
← 具有未来观测 (ot+2s)
以轨迹为条件的 JEPA
ztexec = P([φ(τtexec)], sg[st])
utfut = fDINO(ot+2s)
线性层 Visual Readout Head g → Lfut = (1/M) Σn=1..M [ 1 − simcos(g(znexec), unfut) ]
梯度更新范围：只更新 φ, P, g，不更新 st（Scenario token）

四、分批单独调用机制（Separate Calls）与梯度流向汇总

共用一套 φ → P → H 权重，但三组输入互不混入同一 Self-Attention
第 1 次调用 · 64 条生成候选 Qtgen (64,256)

生成器吐出 τt,1…64 → 经 sg (.detach()) 进 φ 编码成 Qtgen → 送入 P（64 条内部互相 Self-Attention，并与 st 做 Cross-Attention）→ 输出 Ztgen + et 进评分头 H。

第 2 次调用 · 16 条轨迹库候选 Qtbank (16,256)

从当前场景轨迹库随机抽 16 条扰动轨迹 → 过同一个 φ 编码成 Qtbank → 单独送进同一个 P（只在 16 条内部 Self-Attention，不干扰生成候选）→ 输出 Ztbank + et 进同一个 H。

第 3 次调用 · 1 条实际执行轨迹 ztexec (1,256)

日志人类真值轨迹 τtexec 过 φ → 单独送进 P（且对 st 加 sg）→ 输出 ztexec 接线性视觉读出头 g 对齐 +2s 特征。
